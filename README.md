## 🗺️ 제주도 소개

- 🏝️ 대한민국 최남단에 위치한 가장 큰 섬입니다.
- 🌋 화산 활동으로 만들어진 독특한 지형을 가지고 있습니다.
- 🏆 유네스코 세계자연유산, 생물권보전지역, 세계지질공원 3관왕입니다.
- 🗿 돌·바람·여자가 많아 **삼다도(三多島)** 라고 불립니다.
- 🚪 대문이 없는 **삼무(三無)** 의 섬이기도 합니다. (도둑, 대문, 거지)
- 🐴 말과 감귤, 해녀 문화로 유명합니다.
- ✈️ 서울에서 비행기로 약 1시간이면 도착합니다.

### 📌 기본 정보

| 항목 | 내용 |
|------|------|
| 📍 위치 | 한반도 남쪽 해상 |
| 📏 면적 | 약 1,850㎢ |
| 👥 인구 | 약 67만 명 |
| 🏔️ 최고봉 | 한라산 (1,947m) |
| 🗣️ 방언 | 제주어 (유네스코 소멸위기 언어) |
| 🏙️ 행정 | 제주시, 서귀포시 |

## 🌤️ 날씨와 여행하기 좋은 시기

### 🌸 봄 (3~5월)
- 🌼 유채꽃이 노랗게 피어나는 계절입니다.
- 🌸 벚꽃 축제가 열리는 아름다운 시기입니다.
- 🌡️ 평균 기온 10~17도로 여행하기 쾌적합니다.

### ☀️ 여름 (6~8월)
- 🏖️ 협재, 함덕 해수욕장에서 물놀이를 즐길 수 있습니다.
- 🌧️ 장마철에는 비가 자주 오니 우산을 챙기세요.
- 🌡️ 평균 기온 23~28도로 덥고 습합니다.

### 🍁 가을 (9~11월)
- 🌾 억새가 은빛으로 물드는 환상적인 계절입니다.
- 🍊 감귤이 노랗게 익어가는 시기입니다.
- 🌡️ 평균 기온 13~21도로 여행 최적기입니다.

### ❄️ 겨울 (12~2월)
- ⛰️ 한라산 설경이 장관을 이룹니다.
- 🌺 동백꽃이 곳곳에서 붉게 핍니다.
- 💨 바람이 강하니 방한 준비를 하세요.

## 🏞️ 대표 관광지

### 🌋 자연 명소
- ⛰️ **한라산** : 대한민국 최고봉, 백록담이 있는 산
- 🌅 **성산일출봉** : 일출 명소, 유네스코 세계자연유산
- 🕳️ **만장굴** : 세계적인 규모의 용암동굴
- 💧 **천지연폭포** : 서귀포의 대표 폭포
- 🌊 **주상절리대** : 육각형 기둥 모양의 바위 절벽
- 🏖️ **협재 해수욕장** : 에메랄드빛 바다
- 🌿 **비자림** : 수백 년 된 비자나무 숲
- 🌳 **사려니숲길** : 힐링 산책 코스

### 🏛️ 문화 명소
- 🗿 **돌하르방 공원** : 제주의 상징 돌하르방
- 🎨 **본태박물관** : 건축과 예술이 어우러진 공간
- 🏯 **제주 민속촌** : 옛 제주 생활상 체험
- 📚 **제주 4·3 평화공원** : 역사를 기억하는 곳

### 🌺 테마 명소
- 🌸 **휴애리 자연생활공원** : 사계절 꽃 정원
- 🍵 **오설록 티뮤지엄** : 녹차밭과 차 문화
- 🎠 **아르떼뮤지엄** : 몰입형 미디어아트
- 🐬 **돌고래 관찰** : 서귀포 앞바다에서 만나는 남방큰돌고래

## 🍊 제주 특산물

### 🍋 과일류
- 🍊 **감귤** : 제주를 대표하는 특산물, 비타민C 풍부
- 🍊 **한라봉** : 달콤하고 향이 진한 프리미엄 감귤
- 🍊 **천혜향** : 향이 천리를 간다는 고급 감귤
- 🍊 **레드향** : 붉은 빛깔과 높은 당도
- 🍈 **황금향** : 부드러운 과육과 높은 당도
- 🍍 **패션프루트** : 새콤달콤 열대 과일
- 🥭 **애플망고** : 제주 온실에서 재배한 달콤한 망고

### 🥬 농산물
- 🥔 **감자** : 제주 봄 감자는 맛이 일품
- 🥕 **당근** : 전국 최대 생산지
- 🥬 **월동 무** : 겨울에도 푸르게 자라는 무
- 🥦 **브로콜리** : 겨울철 제주 특산 채소
- 🍠 **고구마** : 달콤하고 포슬포슬한 맛
- 🫘 **메밀** : 제주 메밀로 만든 음식이 유명

### 🐟 수산물
- 🐟 **갈치** : 은빛 갈치, 구이와 조림으로 인기
- 🐠 **옥돔** : 제주 대표 생선, 제사상에도 오르는 귀한 어종
- 🦑 **한치** : 여름철 별미, 회와 물회로 즐김
- 🐚 **전복** : 해녀가 직접 채취하는 고급 해산물
- 🐙 **문어** : 쫄깃한 식감
- 🦪 **성게(보말)** : 제주 바다의 맛

### 🐖 축산물
- 🐷 **흑돼지** : 쫄깃하고 고소한 제주 대표 고기
- 🐴 **말고기** : 제주만의 독특한 식문화
- 🐮 **제주 한우** : 청정 환경에서 자란 소고기

### 🎁 가공 특산품
- 🍫 **한라봉 초콜릿** : 기념품으로 인기
- 🍵 **제주 녹차** : 오설록 대표 상품
- 🍯 **귤피차·청귤청** : 건강 음료
- 🍪 **오메기떡** : 차조로 만든 전통 떡
- 🍶 **오메기술** : 제주 전통주
